# Font Licenses

This file accompanies the font files served with the game build (see `fonts/*.ttf`). It is included so that every copy of the OFL-licensed fonts contains the required copyright notice and license text (SIL OFL 1.1, clause 2).

The full, verbatim license text ships in [`OFL.txt`](OFL.txt), in this same directory. Do not edit it by hand — replace it with a fresh copy from <https://openfontlicense.org/documents/OFL.txt> if it ever needs updating.

Repository-wide inventory: [`THIRD_PARTY_ASSETS.md`](../../../../../THIRD_PARTY_ASSETS.md).

## Obligations

- Keep `OFL.txt` next to the font files so it ships with every copy of them.
- Do not rename or rebrand the fonts (all three have Reserved Font Names — a modified font may not use the original name without written permission from the Copyright Holder).
- Do not redistribute the font files under any other license.
